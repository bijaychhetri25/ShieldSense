# Data Card — ShieldSense Synthetic Scam-Message Dataset v0.2

**Author:** Jaskaran Singh — Data & Labelling Lead
**Date:** 15 October 2026
**Status:** v1.0 Final

## 1. Dataset Name

ShieldSense Synthetic Scam-Message Dataset v0.2

## 2. Purpose

Supports training and evaluation of a lightweight text classifier that labels SMS/chat messages as Low, Medium or High risk. Used to compare a rules-based baseline against a trained classifier.

## 3. Source

- Synthetic messages: Generated by the project team using patterns from public scam-awareness resources.
- Public datasets: None used at this stage. If used, licensing will be documented here.
- No real personal messages: No real SMS, no real phone numbers, no real names, no scraped inboxes.


## 4. Size and Distribution

- **Total:** 202 messages
- **Low risk:** 68 messages (33.7%)
- **Medium risk:** 67 messages (33.2%)
- **High risk:** 67 messages (33.2%)
- **Hard negatives:** 108 messages — legitimate service notifications that resemble scams

## 5. Labelling

- **Taxonomy:** ShieldSense Risk Taxonomy v2.0
- **Protocol:** ShieldSense Labelling Protocol v1.0
- **Primary labeller:** Jaskaran Singh (JS) — all 202 dataset messages
- **Double-labelled sample:** 30 messages labelled independently by all four team members (Jaskaran, Kapil, Alisha, Bijay) for inter-rater agreement
- **Agreement metric:** Cohen's kappa (primary), percentage agreement (secondary)
- **Agreement result:** Average kappa = 0.832 (Almost perfect), 89.5% agreement
- **Adjudication:** Documented in `inter-rater-agreement-report.md`

## 6. Held-Out Test Set

- **Split ratio:** Stratified 80/20 (162 train / 40 test)
- **Split date:** 8 October 2026
- **Split method:** Stratified by risk label using fixed random seed (42)
- **Test set file:** `test-set.csv` (40 messages)
- **Training set file:** `training-set.csv` (162 messages)
- **Test set composition:** 14 Low, 13 Medium, 13 High
- **Lock status:** LOCKED as of 8 October 2026
- **Lock note:** See `test-set-lock.md`
- **Leakage check:** - COMPLETED 8 October 2026 — PASS (zero overlap between training and test sets). See `leakage-check-report.md`.

## 7. Ethical Constraints

- Synthetic and publicly available data only.
- No real personal messages, ever.
- No real phone numbers or names.
- English short-text only.
- No public deployment.
